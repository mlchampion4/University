# Лабораторная работа: Информационная система «Университет»

Программа реализует объектно-ориентированную модель университета на языке **C++**, позволяющую управлять структурой учебного заведения, распределением нагрузки и успеваемостью студентов.

## 📌 Вариант 11. Университет

### Описание предметной области
Университет имеет иерархическую структуру, состоящую из **факультетов** и **кафедр**:
* **Кафедры:** закрепляют за собой штат преподавателей.
* **Факультеты:** организуют обучение студентов.

**Процесс обучения и учет данных:**
1. Преподаватели ведут определенные учебные дисциплины.
2. Для каждой дисциплины хранится: *название*, *количество академических часов* и *форма контроля* (экзамен/зачет).
3. Студенты записываются на доступные дисциплины.
4. Система учитывает **учебную нагрузку** (какие курсы ведут преподаватели) и **результаты студентов** (оценки/успеваемость по дисциплинам).

---

## 💻 Функционал программы
* Создание и управление структурой (Добавление факультетов, кафедр, преподавателей и студентов).
* Регистрация студентов на учебные курсы.
* Расчет и вывод учебной нагрузки преподавателей.
* Ведение учета успеваемости (выставление оценок) и вывод результатов студентов.

---

## 🛠️ Архитектура проекта (Классы)
Проект спроектирован с использованием ООП и включает следующие ключевые классы:
* `University` — главный управляющий класс (содержит списки факультетов и кафедр).
* `Faculty` — факультет (хранит данные о студентах).
* `Department` — кафедра (хранит данные о преподавателях).
* `Teacher` — преподаватель (информация о нагрузке и ведении дисциплин).
* `Student` — студент (список выбранных курсов и оценки).
* `Subject` — учебная дисциплина (название, часы, форма контроля).

## 🚀 Сборка и запуск

### Требования
* Компилятор с поддержкой стандарта **C++11** или выше (GCC / Clang / MSVC).
* Установленная утилита `make` или настроенный VS Code.

### Компиляция через терминал
```bash
g++ -std=c++11 main.cpp -o university_app
```

### Запуск
```bash
./university_app
```
